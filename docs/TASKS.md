# 当前任务与范围

本文档记录当前阶段的可维护范围、边界和执行标准。普通功能提交不需要把这里当 changelog 更新；只有项目阶段、范围或工作规则变化时才更新。

## 当前阶段

SnapNook 当前处于截图、编辑器、OCR 和 V4 滚动截屏能力的维护迭代阶段。

已完成并允许继续维护：

- 菜单栏常驻
- `Capture Area`
- `Capture Text`
- `Preferences`
- `Quit`
- 全局快捷键
- 权限检查与系统设置引导
- 非激活全屏框选 overlay
- `ESC` 取消截图或 OCR 框选
- 截图后左下角浮动预览
- 预览中手动复制原图
- 预览中手动保存 PNG
- 预览中进入编辑器
- 编辑器标注、图片效果和已有裁剪能力
- 本地 OCR 和纯文本复制
- `Scrolling Capture` 手动滚动捕获

## 当前允许维护的滚动截屏能力

- 菜单栏入口 `Scrolling Capture`
- 独立滚动截屏选择框，不混入普通 `Capture Area`
- 开始前选择框内部拖动只移动，边框和控制点才调整大小
- `Start Capture` 后选择框固定，底层页面滚轮正常滚动
- ScreenCaptureKit 连续捕获选区内容，排除 SnapNook 自身，不反复隐藏或显示 overlay
- 右侧长图预览显示 `Capturing...` 和当前高度，不显示帧数
- `ScrollingStitcher` 校验相邻视口和末端锚点，只追加可靠新增内容；静止和向上回看不追加
- 鼠标移出选区暂停，失配等待重叠恢复，64MP 超限保留当前结果
- `Done` 后复用现有浮动预览，继续支持 `Copy`、`Save`、`Edit`
- `Cancel` 或 `ESC` 取消时清理临时状态，不保存、不复制、不显示预览
- 仅支持手动垂直滚动；自动滚动不在当前范围

- 箭头整体移动、起点/终点调整

- 模糊框移动、控制点缩放和区域内模糊渲染

## 当前允许维护的 OCR 能力

- 菜单栏入口 `Capture Text`
- 复用区域框选 overlay，并区分截图和 OCR 选择模式
- 文字框选完成后直接截取选区原图
- 使用 Vision `VNRecognizeTextRequest` 做本地 OCR
- 识别语言限定为 `zh-Hans` 和 `en-US`
- OCR 成功后自动复制纯文本到剪贴板
- OCR 空结果不覆盖已有剪贴板内容
- 可在 `Preferences` 中为 `Capture Text` 设置全局快捷键
- 通过轻量 HUD 提示：
  - `Recognizing text...`
  - `Text copied.`
  - `No text recognized.`
  - `OCR failed.`

## 当前不要实现

除非有明确需求，不要实现或提前铺设抽象层：

- 录屏
- 云同步
- 登录或账号系统
- 自动更新
- OCR 结果编辑面板
- OCR 历史记录
- OCR 自动翻译
- OCR 结构化导出
- 复杂图层面板

## 修改原则

- 先确认需求，再修改代码。
- 如果一个需求有多种合理解释，应先列出差异并提问。
- 只修改和当前需求直接相关的文件。
- 不要顺手重构、改格式或清理无关代码。
- 不要为了单次使用代码新增抽象层。
- 不要添加未要求的灵活性、配置项或兜底流程。
- 只清理自己本次修改造成的废弃 import、变量或函数。
- 如果发现无关死代码，可以提醒，但不要擅自删除。

## 可验证目标

开始实现前，把需求转成可验证目标：

- 修复 Bug：先确认或补充能复现问题的验证方式，再修复。
- 添加校验：先明确无效输入和预期行为，再实现。
- 调整 UI：先明确交互前后状态，再验证对应流程。
- 改导出：先明确导出尺寸、内容和不应包含的预览元素。

多步任务建议使用这种格式规划：

```text
1. [步骤] -> 验证: [如何检查]
2. [步骤] -> 验证: [如何检查]
```

## 关键实现边界

- 截图和 OCR overlay 必须保持非激活，不能导致其他 App 的菜单、弹窗或临时 UI 因失焦消失。
- 选区完成后必须先隐藏 overlay，再截图，避免把选区框截进图片。
- 滚动截屏的捕获态不能反复隐藏和显示 overlay；选择框、控制按钮和预览面板不能进入最终长图。
- 滚动截屏不能阻止底层 App 接收滚轮事件。
- 浮动预览定位必须基于 `NSScreen.visibleFrame`，不能写死屏幕坐标。
- 浮动预览窗口尺寸固定为 `300x180`。
- 复制和保存必须使用原图或原始 PNG 数据，不得使用缩略图。
- OCR 只允许在非空文本时清空并写入剪贴板。
- 标注数据必须保存为原始图片坐标。
- 选中框、控制点、辅助线只允许出现在预览中，不能导出。
- `Blur` / `Mosaic` 只能作用于各自 rect 内。
- `Highlight` 必须导出聚光灯效果。
