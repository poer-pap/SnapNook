# Scrolling Capture 实现与验收

## 已确认范围

借鉴 CleanShot 操作流程，沿用 SnapNook 风格：当前鼠标所在显示器内拖拽框选、移动与八点微调、Start、手动向下滚动、实时长图预览、Done 后进入现有 Copy / Save / Edit。用户自行排除固定区域和滚动条。不加入自动滚动、横向捕获、固定区域自动识别或新设置。

## 实现

- `ScrollingCaptureStream`：按显示器 ID 创建 ScreenCaptureKit 流；显示器局部坐标以左上为原点，输出尺寸使用屏幕 backing scale。30 fps、queueDepth 3、完整帧、无鼠标、无音频，排除当前进程的所有窗口。
- `ScrollingCapturePipeline`：接收时判断鼠标是否在选区，暂停期间丢弃新帧；此前已接收的帧仍可完成。锁保护一张处理中帧和一张可替换的最新待处理帧，串行后台转换、匹配、预览、最终合成和 PNG 编码。
- `ScrollingStitcher`：缩小灰度图粗搜，原图逐行精搜；至少 25% 重叠，拒绝弱匹配与不唯一的位移。向上只更新可靠视口位置，向下越过末端时直接验证末端锚点。失配不更新可靠基准。
- 首帧和新增部分复制为独立原始分辨率条带；预览最多约 196×380 像素，刷新间隔至少 150ms，追加时不重绘完整长图。Done 才合成最终图。
- 总量上限 64,000,000 原图像素，下一条带会超限时停止接收并保留当前结果。
- Done 冻结接收并排空待处理帧。Cancel 使迟到结果失效，不显示预览、不保存、不复制。窗口隐藏后延后一轮主循环关闭；会话临时注册 Carbon Escape，不增加权限或持久化设置。

## 自动化验证

`Tests/SnapNookTests/ScrollingStitcherTests.swift` 覆盖：

- 向下连续与奇数像素位移，逐像素对比完整参考图。
- 静止、向上回看、返回末端与再次向下，不重复追加。
- 失配保留基准并恢复，重复纹理拒绝，超限保留当前结果。
- Done 排空接收帧，暂停丢弃新画面，有界缓冲只保留最新待处理帧。
- Cancel 后待处理及迟到帧不完成。
- 外接显示器偏移与 1×/2×输出配置。
- 2048×1536 视口、20 屏内容（最终 2048×30720，62,914,560 像素），与完整参考图逐像素比较。
