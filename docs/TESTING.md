# 手动验证清单

每次修改后至少构建成功，并验证本次直接影响的流程。如果修改涉及截图、OCR、预览、编辑器渲染或导出，还要验证相邻流程没有明显回归。

## 构建

推荐命令：

```sh
env DEVELOPER_DIR=/Users/loners/Downloads/Xcode-beta.app/Contents/Developer bash scripts/build_app.sh
```

缓存受限时：

```sh
mkdir -p .build/tmp-home .build/module-cache
env HOME=$PWD/.build/tmp-home \
  CLANG_MODULE_CACHE_PATH=$PWD/.build/module-cache \
  DEVELOPER_DIR=/Users/loners/Downloads/Xcode-beta.app/Contents/Developer \
  bash scripts/build_app.sh
```

运行：

```sh
open .build/SnapNook.app
```

## 基础应用

1. App 启动后只显示菜单栏图标/标题，不显示 Dock 主窗口。
2. 菜单包含 `Capture Area`、`Capture Text`、`Scrolling Capture`、`Preferences`、`Quit`。
3. `Preferences` 中可设置 `Capture Area` 和 `Capture Text` 全局快捷键。
4. `Capture Area` 默认值为 `Option + Shift + S`。
5. `Capture Text` 默认不占用快捷键。
6. 无权限时，触发截图会弹出授权提示，并能打开系统设置。

## Capture Area

1. 有权限时，触发截图会进入半透明遮罩模式。
2. 拖拽选区后会完成截图。
3. `ESC` 能取消截图。
4. 拖拽宽高小于阈值时取消，不截图。
5. overlay 不应激活 SnapNook，也不应导致其他 App 的菜单或弹窗因失焦消失。

## Scrolling Capture

1. 点击 `Scrolling Capture` 后出现默认选择框。
2. 选择框中心区域拖动只移动选择框，不改变大小。
3. 拖动边框或 8 个控制点才调整选择框大小。
4. 选择框不能完全移出当前屏幕 `visibleFrame`。
5. 点击 `Start Capture` 后选择框固定，不能移动或 resize。
6. 捕获过程中底层网页或文档能正常响应鼠标滚轮。
7. 捕获过程中屏幕不应因 overlay 反复隐藏和显示而闪烁。
8. 右侧预览显示 `Capturing...` 和当前高度，不显示 `frames` 数量。
9. 右侧预览显示的是当前长图缩略图，而不是最近一帧。
10. 选择框、控制按钮和右侧预览面板不能被截进最终长图。
11. 缓慢向下滚动时，最终长图应尽量连续，不应出现大块重复视口。
12. 重复或几乎静止的画面不应明显增加长图高度。
13. 点击 `Done` 后生成一张最终长图，并显示在现有浮动预览中。
14. 最终长图可继续 `Copy`、`Save`、`Edit`。
15. 点击 `Cancel` 放弃，不保存、不复制、不显示浮动预览。
16. 捕获过程中按 `ESC` 等同于 `Cancel`。
17. 连续多次启动和取消 `Scrolling Capture` 不应崩溃。
18. 当前 V4.0 主要验证手动向下滚动；虚拟列表、动画区域、视频区域或滚动过快时拼接允许不完美，但不能崩溃。

## 浮动预览

1. 截图完成后在目标屏幕 `visibleFrame` 左下角显示浮动预览，距离左边和底部约 24 px。
2. 浮动预览窗口尺寸固定为 `300x180`，不能跟随截图原图尺寸变化。
3. 浮动预览默认显示截图缩略图，不抢主窗口焦点，不显示 Dock 图标。
4. 缩略图必须在固定预览区域内按比例完整显示，不能拉伸变形。
5. 超宽图、超高图、小图都要正确显示。
6. 鼠标移入预览后显示 `Copy`、`Save`、`Close` 操作，并显示 hover 背景。
7. 鼠标移出后恢复普通缩略图状态。
8. 点击 `Close` 后立即关闭当前浮动预览，不保存图片，不复制图片，不弹确认框。
9. 点击 `Copy` 会复制当前截图原图到剪贴板，不能使用缩略图。
10. 复制成功后浮动预览关闭，且不会自动保存文件。
11. 点击 `Save` 会弹出 macOS 原生 `NSSavePanel`。
12. 默认文件名为 `SnapNook-yyyyMMdd-HHmmss.png`。
13. 用户确认保存后才写入原始 PNG 数据。
14. 用户取消保存时预览保持显示。
15. 默认 8 秒后自动关闭预览。
16. 鼠标悬停时暂停自动关闭。
17. 多显示器下预览优先出现在截图区域所在屏幕，兜底为当前鼠标所在屏幕。

## 编辑器基础

1. 浮动预览左下角 `Edit` 可以打开编辑窗口，并显示截图原图。
2. 编辑窗口缩放后，已有标注必须继续和图片内容对齐，不能漂移。
3. 新标注创建完成后应自动回到 `Select`。
4. 新标注应立即可被再次点击选中并进入二次编辑。
5. 点击空白区域时取消当前选中。
6. `Backspace` 删除当前选中标注。
7. 当前正在编辑文字时，`Backspace` 只能删除文本内容，不能误删整个标注。

## 编辑器标注

1. 选择 `Rectangle` 后，在图片区域内任意方向拖拽可创建矩形。
2. 矩形拖拽过程有实时预览，宽或高小于 `5 px` 时忽略。
3. `Rectangle` 选中后显示高亮边框和 8 个控制点。
4. 点击矩形内部可以移动，点击控制点可以调整大小。
5. 选择 `Arrow` 后，在图片区域内拖拽可创建箭头。
6. 箭头拖拽过程有实时预览，长度小于 `8 px` 时忽略。
7. `Arrow` 选中后显示起点/终点控制点。
8. 点击箭头线段可以移动，点击起点或终点可以调整方向/长度。
9. 选择 `Text` 后，点击图片区域应创建默认文字框并立即进入编辑。
10. 空文本点击外部后取消，不生成 annotation。
11. 有内容时点击外部后保存。
12. `TextAnnotation` 选中后可移动，可通过 8 个控制点调整大小。
13. 双击文字框应再次进入编辑。
14. 选择 `Highlight` 后，拖拽创建的区域表现为聚光灯效果：区域内保持原图，区域外变暗。
15. `Highlight` 选中后支持移动和 8 个控制点缩放。
16. 选择 `Blur` 后，拖拽创建的区域只在框内显示模糊效果。
17. `Blur` 拖拽过程有实时预览，宽或高小于 `5 px` 时忽略。
18. 选择 `Mosaic` 后，拖拽创建的区域只在框内显示马赛克效果。
19. `Mosaic` 拖拽过程有实时预览，宽或高小于 `5 px` 时忽略。
20. `Select` 下点击已有 `Blur` / `Mosaic` 必须选中该标注。
21. `Blur` / `Mosaic` 选中后支持移动、8 个控制点缩放和 `Backspace` 删除。

## 编辑器裁剪

1. 选择 `Crop` 后显示裁剪框和裁剪操作按钮。
2. 裁剪框应可移动和通过控制点调整。
3. `Apply` 后导出区域使用当前裁剪区域。
4. `Cancel` 或 `ESC` 后退出裁剪模式，不改变当前导出区域。
5. 切换到其他工具时，未应用的裁剪交互应取消。

## 编辑器导出

1. `Save as...` 导出的是“原图 + 当前 annotations”的合成 PNG。
2. 未裁剪时导出尺寸等于原始截图尺寸。
3. 已应用裁剪时导出尺寸等于裁剪区域尺寸。
4. 导出不能包含选中框、控制点或辅助虚线。
5. 文字导出时只导出文字内容，不导出编辑态边框和控制点。
6. `Highlight` 导出必须包含聚光灯效果。
7. `Blur` / `Mosaic` 必须只作用于各自 rect 内，区域外保持原图。
8. 保存结果不能上下反转。

## Undo / Redo

1. `Undo` / `Redo` 覆盖新增标注操作。
2. `Undo` / `Redo` 覆盖更新标注操作。
3. 拖拽过程中不要逐帧入栈，只在 `mouseUp` 时记录一次操作。

## Capture Text / OCR

1. 点击 `Capture Text` 后，进入独立文字框选模式。
2. OCR 选区样式与普通截图模式可区分，显示浅灰半透明矩形和右下角宽高数字。
3. 宽高数字显示实际截图像素尺寸，不是 point。
4. Retina 和多显示器下选区截图必须与普通 `Capture Area` 一致稳定。
5. 框选完成后，不显示浮动预览。
6. 框选完成后，不打开编辑器。
7. 框选完成后，不保存图片。
8. 框选完成后，直接对选区原图执行 OCR。
9. OCR 识别中显示 `Recognizing text...`。
10. OCR 成功后自动将纯文本复制到剪贴板，并显示 `Text copied.`。
11. 未识别到文字时显示 `No text recognized.`，且不能覆盖已有剪贴板内容。
12. OCR 失败时显示 `OCR failed.`。
13. `ESC` 取消时，不截图、不 OCR、不复制。
14. 拖拽宽高小于 `5 px` 时取消，不截图、不 OCR、不复制。
